Sistema de Cadastro de Funcionários
Objetivo: gerenciar funcionários de uma empresa.

Conceitos: listas de objetos e métodos de classe.


Crie as classes:
- Funcionario
- Empresa
Requisitos:
1. Funcionário possui nome, idade, cargo e salário.
2. Empresa armazena vários funcionários.
3. Cadastrar funcionários.
4. Remover funcionários pelo ID.
5. Buscar funcionário pelo nome.
6. Listar funcionários.
7. Calcular a folha salarial total.
8. Aumentar salário de determinado funcionário.
